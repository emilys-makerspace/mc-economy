# Approved market index launch policy

The user approved this launch policy on 2026-11-17. Publish original in-game benchmarks so players can see how the simulated market and each venue's stock universe are moving. Show the index level, change since the previous UTC day-end, a history chart, and the dated constituent list and weights.

| Decision | Approved launch rule |
| --- | --- |
| Benchmarks | One global index and one per catalog venue, using eligible ordinary shares from the curated catalog. The global index uses one representative listing per issuer. Each venue index uses one listing per issuer on that venue. A cross-listed issuer can appear in multiple venue indices and contributes once globally. Each methodology manifest names the representative listings. |
| Weighting | Give each constituent equal weight at launch and rebalance weekly on Monday at 00:00 master UTC. Weights drift between rebalances as prices move. Membership changes take effect through a dated methodology revision. Scheduled changes preserve continuity, with the next complete snapshot used if required inputs are missing at the scheduled boundary. |
| Prices and currency | Use the published B3 model reference marks at the 60-second cadence, with versioned in-game FX at the same effective boundary. The global index uses CAD. Each venue index has a single disclosed base currency. Start each index at 1,000 at its first complete live snapshot. Model-based levels can update while a venue is closed and remain labeled as such. |
| Returns | Publish price-return indices. Dividend cash is outside the price series. Ordinary ex-dividend price movement appears through the underlying mark. Adjust index quantities for share splits and rebalances so the mechanical change does not move the headline index level. |
| Coverage and gaps | Approve and disclose the launch constituents before activation. If an included mark or FX rate later becomes unavailable, show the last complete level with its original timestamp and show the coverage gap. Leave the missing interval blank in history. Resume from the next complete snapshot using the existing methodology, subject to any effective action or rebalance. |
| Player-company shares | Keep the launch benchmarks tied to the curated universe. A player listing remains visible in its own market and chart. |

For example, with two equally weighted stocks and flat FX, if one goes up 10% and the other is flat, the index moves from 1,000 to 1,050. A subsequent 2-for-1 split doubles the split stock's index quantity and halves its unit price, preserving the level. A funded merger or delisting uses the recorded terminal consideration where available, so a constituent removal preserves the return experienced before it leaves. A missing terminal mark or consideration uses the coverage-gap rule until an authoritative outcome or a documented methodology revision resolves it.

Save each published point with its effective UTC time, methodology and source revisions, and coverage. Retain the 60-second and UTC day-end series within the accepted retention bounds. Historical levels keep their original membership, price and FX inputs. Market data and index calculations remain read-only for cash, custody and trading.
