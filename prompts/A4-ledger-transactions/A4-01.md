# A4-01 · Posting model

Approved for execution under the [A4 execution contract](EXECUTION.md). Execute only when this ID is explicitly invoked. The main agent owns integration and verification. Confirm prerequisites and use the project baseline and verification instructions.

## Prerequisites

A1 journal and A2 monetary types. See the [journal contract](../../.codex/architecture/journal.md), [accounts contract](../../.codex/architecture/accounts.md), [A2-04 quote handoff](../../.codex/A2/A2-04.md) and [A2-05 denomination handoff](../../.codex/A2/A2-05.md) as applicable.

## Scheduling and configuration

Define account roles, signs, allowed postings and trusted issuance/redemption authority. Store immutable versioned posting facts with one transaction identity. Check arithmetic and balance independently in each currency before writing.

Limit implementation to this package. Use existing server authority and journal admission. Leave cash items, custody, and external integrations to their owning phases.

## Diagnostics

Identify invalid roles, currencies, imbalance and overflow without leaking account data.

## Foundation acceptance

Verify 100 coins issued with a matching counterentry, unauthorized issuance, overflow and a batch that nets to zero only across currencies. Hand off the posting contract to A4-02.

Record the contract, checks run, and any unresolved prerequisite in the handoff. Stop before implementing the next ID.
