# A3-04 account queries and funds vocabulary

Verified. Owner queries use scoped ID lookups and bounded history pages. A
server-operator inspection commits a receipt scoped to the owner and query
before accessing account rows. The live command audience is checked again
before the read and before delivery.

`AccountFunds` v1 describes disjoint available, reserved and restricted
minor units for one currency with checked posted totals. Authorized funds
queries report `LEDGER_UNAVAILABLE` until A4 supplies a ledger. The read-only
`FundingEligibility` contract gives A4/B2 account revision and currency checks
and leaves trading currency policy to B2.

A3-05 can use the catalog and closure eligibility contracts for its bounded
planner. It also requires the verified A2-05 confirmation and denomination
revision contract. The project index still records chooser acceptance as
pending.
