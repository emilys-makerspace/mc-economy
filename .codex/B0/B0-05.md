# B0-05 · Corporation integration API

The [version 1 Java contract](../../docs/INTEGRATION_API.md#corporation-api-version-1) implements approved C08 and BD10. The server authenticates a provider against the calling mod module and issues a session-scoped handle. Schema 59 persists external bindings and revisioned mandates. The founder reviews registration, binding and scope changes. Registration and its binding share the original incorporation fee transaction. Payments record the integration actor and settle through corporate banking. Banking wire version remains 14.

## Verification

On Java 21, the [SQLite test](../../src/test/java/ca/emilybelnavis/mcmods/economy/corporation/IntegrationBindingsTest.java) passed. It checked one CAD 500 fee on repeated registration, a changed request conflict, isolation across providers and account scopes, disabled and revoked spending, payment balances, and original receipt recovery after reopening. The [test-source consumer](../../src/test/java/ca/emilybelnavis/mcmods/economy/example/CorporationIntegrationConsumer.java) compiled against the public facade.

The package build, Gradle runClient task lookup and runClient dry run passed. These checks exercised the domain on SQLite and compiled the NeoForge and chat entry points. Live external-mod registration, multiplayer confirmation, crash injection and a concurrent disable were outside the verified scope.
