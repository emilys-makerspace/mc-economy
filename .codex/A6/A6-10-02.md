# A6-10-02 — Debt diagnostics

Implemented and verified 2026-11-05. Private owner commands expose card/loan payments, original report revisions and collection clocks/accounting history. Player-backed operator commands provide separately audited bounded facility, report and receipt inspection, including pre-default arrears, original obligations, cure, sale failures, acknowledgement and independent expiry reasons.

Current creditor receivable and borrower liability witnesses reconcile to posted accounts. Selected case debt reconciles to the frozen facility. Provider cursors redact other target identities. Original missed snapshots remain distinct from later cure receipts, paid defaults, uncollectable claims and expired reports.

V32 adds three diagnostic indexes. Existing facts/versions, monetary entities and providers retain their contracts. Commands use the existing private reply path. Owner and inspection service APIs remain grant-separated, with fresh audit per operator page and session/privilege rechecks before publication.

[Contracts and API details](../architecture/debt-diagnostics.md) and [verification evidence](verification/A6-10-02.md) record coverage and limits. Automatic append-only cure corrections retain their original history. No separate manual correction workflow was added because the approved policy defines automatic cure correction without a manual operation contract.
