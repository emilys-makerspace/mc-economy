# A6-09-02 — Loan diagnostics

Implemented 2026-11-05. Owner commands expose captured fixed loan terms, current/saved debt, immutable schedule/installment pages, original application decisions and revision-bound payoff previews. Separate player-backed operator commands durably audit every inspection before exposing underwriting, funding, payment/journal reconciliation or monthly catch-up state.

All pages and folds are bounded. Loan events bind immutable owner/world snapshots; colliding application UUID selections cannot expose another applicant's denial. Original rates and schedules are never rewritten, and missing prime/monthly work are explicit. Schema V29 adds one history index only; no new table or financial fact/version is introduced. Existing InspectionAudit v1 supplies receipts.

Production borrowing remains gated pending lifecycle safety. No application/payment GUI, financial mutation command, reporting/default/collections/autopay, recurring scoring or B6 collateral adapter is enabled.
