# A6-08-02 — Credit diagnostics

Implemented 2026-11-05. Owner banking pages now list facilities and show limit/headroom, purchase/advance APRs and buckets, posted/current/exact balances, frozen statement amounts, outstanding minimums, due dates and past-due requirements. Frozen statement history is paged and labelled in the contract currency. No application, draw, payment or editing action is added.

`/economy credit facility <facility>` is an owner read. Player-backed operators use `/economy credit inspect <owner> <facility> [daily|payments|events] [after <sequence> <position> [allocation_offset]]`. Each page is durably audited before data is read; a narrow inspection-only path works during financial catch-up. Other financial writes remain gated. Foreign owner IDs and invalid authority return no private view; token references are never displayed.

New v1 immutable daily input and repayment allocation receipts commit with their existing financial operation. Daily diagnostics verify captured calculations using stored APR/bucket inputs; older events retain explicit unavailable-input/allocation labels. Schema V26 adds four indexes only. Ledger/journal and outstanding-facility reconciliation uses bounded windows and explicit incomplete flags, never a partial total labelled as a full balance.
