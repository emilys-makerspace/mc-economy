# A2-05 — World denomination and change protocol

The first connected player receives a session-bound /economy choose
command. The server checks the lease and actor before journal admission.
An unresolved selection retains the original operation ID. A fresh
session reads the committed publication before offering a chooser.

DenominationChange supplies a session-scoped two-confirmation contract
for A4. A4 owns live permission revocation and revision checks at its
authoritative boundary and the atomic commit of denomination and account
effects. HistoricalMoney retains the original amount and optional frozen
display with day and publication provenance.
