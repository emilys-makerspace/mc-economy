# A2-01 — Currency registry and monetary types

Implemented and verified on 2026-11-03. See [verification evidence](verification/A2-01.md).

- `EconomyCurrency` is the immutable registry for both server types. Use its
  exact uppercase code as identity. The historical CAD rate is an exact
  decimal in CAD per major unit for A2-03.
- `Money` stores signed whole minor units as a long and checks currency and
  overflow in arithmetic. `Price` stores exact decimal major units and
  supports fractional minor units.
- `MoneyFormatter` displays the currency code by default and falls back to
  en-CA for missing locales and locales without a language.
- A2-02 owns conversion and settlement rounding. A3 owns account sign and cap
  rules. A4 uses the shared types for financial posting.

Future persistence follows the [storage](../architecture/storage.md) and
[journal](../architecture/journal.md) contracts.
