# A5-02-02 · Custody diagnostics

Trusted integrations can call LedgerService.inspectCustody,
inspectCustodyWitness and inspectCustodyOperation. Admission uses the
server-authenticated actor; live operator authority is checked on the storage
worker. Owners see their own cases and operators may inspect the world.

Pages filter all cases, quarantine or unresolved backlog before applying an
exclusive case-ID cursor. Page size is 1–63 with one lookahead row.
pageLimitReached signals another matching case. No unbounded total is counted.

Witness inspection reads only the selected authorized case's persisted
reservation or delivery location, capped at 1 MiB. It distinguishes absent
evidence, missing files, match, mismatch, scan limit, unsafe location,
unavailable storage and unsupported witness formats. A match observes file
identity at sample time and does not resolve a custody case.

Exact operation inspection returns the immutable custody snapshot, original
operation and transaction IDs, journal sequence, actor, action, UTC audit time
and stable result code. Snapshot evidence correlates the journal event with
its save witness. Rejected operations have no custody fact and are omitted.
