# A5-05 · Deposits

Delivered schema V15 deposit preview/reservation/settlement and exact-original
returns through trusted server APIs and a Minecraft inventory adapter.
Preview freezes account, terminal and FX revisions. ATMs enforce bills;
tellers admit bills and coins. Credit floors each source-currency subtotal to
the whole bank quantum. All-skipped deposits return every original.

Cash quantity locks prevent competing redemption. Settlement atomically
credits the account, consumes payable issued quantities and records skipped
return intents. Partial direct returns retain exact saved remainders, which
become owner-bound custody claims only with proof of non-delivery.
Uncertain recovery routes originals to operator review without releasing
quantity protection or guessing a delivery.
