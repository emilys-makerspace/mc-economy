## Limits

No stock trading, credit product, external claim-protection integration or automatic compensation GUI is introduced. Restored/uncertain cases deliberately require conclusive operator evidence. Live semantic bank-v1/bank-source-v1 witness references are retained in audit records; the older standalone full-file v1 diagnostic observer can report UNSUPPORTED for those formats. Changing later player files does not itself prove loss or authorize redelivery. Files/metadata/chunk observations are bounded to 1 MiB, so unusually large third-party state is rejected rather than certified. Hardware power loss and every possible third-party container mutation are not claimed by these process/file tests.
