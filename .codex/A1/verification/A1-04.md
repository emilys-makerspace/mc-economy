## New fixture evidence

ProjectionRecoveryTest: rebuild equals the committed generic authoritative counter; no half-built
snapshot is exposed; committed generation/checkpoint resumes; replacement activates atomically;
damaged derived state rebuilds; unknown committed records reject BEFORE upgrade/rebuild.

EconomicClockTest: same seed/world produces identical update IDs/seeds/outputs and chronological
same-time dependency order across batch sizes 1 and 16 with restart; already committed decisions
are not rerolled by backward time; explicit future version boundary preserves overdue old versions;
forward jumps retain debt through a backward jump; missing historical implementations fail; output
effects/completion/journal roll back together. No actual game-time/sleep input exists in this API.

RuntimeStartupTest: real ServerServices/storage worker remains INITIALIZING and gates requests
until journal validation, initial projection recovery, economic catch-up and final projection
validation complete. Final derived checkpoint includes clock records. Shutdown and separate
post-save witness are exercised with an explicit fixture-world save boundary.

RecoveryProcessTest (actual process termination): launches its own child JVMs, never user's games.
Kill an uncommitted rebuild batch after a cell change but before checkpoint commit; reopen resumes
the original generation and produces the exact committed count, with no duplicate effects. Kill
economic work before completion commit and after commit; restart preserves or recomputes only
uncommitted work with the same stable ID/seed, completing once and retaining the original output.
These checks are distinct from exception-injected rollback and cancellation tests retained from A1-03.

WorldBackupTest: complete world/region files restore together with UUID/last journal/derived state;
post-backup player-fixture actions remain only in the original world. Corrupted files, incompatible
but rehashed manifest, active world, DB-close-only state, changed session stamp and existing target
all reject safely; current files remain intact. A restored clean world can be backed up again.

WorldBackupClockTest: restore a nonzero economic checkpoint, advance UTC, and catch up only new
intervals while retaining the committed update/output prefix; original world remains at its prior
checkpoint. OfflineWalTest constructs a quiescent committed-WAL fixture and verifies inspection
reads WAL state without adding/changing source companions; this fixture construction is NOT the
production backup protocol.
